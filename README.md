Task 2: Calculator

Project Description

This project is a simple calculator developed using Python. It performs basic arithmetic operations such as addition, subtraction, multiplication, and division. After displaying the result, the user can perform another operation with the same numbers, enter new numbers, or exit the program.

Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Perform multiple operations using the same numbers
- Enter new numbers whenever required
- Handle division by zero
- Handle invalid operations
- Exit the calculator whenever needed

Technologies Used

- Python 3
- Visual Studio Code (VS Code)

How to Run the Project

1. Install Python 3 on your computer.

2. Open the project folder in VS Code.

3. Open the terminal.

4. Run the following command:
   
   "python calculator.py"

5. Enter two numbers.

6. Select an arithmetic operation.

7. View the result.

8. Choose whether to perform another operation, enter new numbers, or exit.

Concepts Used

- Variables
- User input and output
- Type conversion using "float()"
- Arithmetic operators
- Conditional statements ("if", "elif", "else")
- Loops ("while")
- Error handling using conditional statements
